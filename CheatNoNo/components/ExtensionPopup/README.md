The extension popup is the toolbar window that shows the current status: not on an exam, exam active, or locked.

The consumer provides the status, exam title, signed-in email, strike count and elapsed time. It is 340px wide with `shadow-lg`. Idle offers a self-check; active shows the timer and strikes; locked shows the pause banner and a message button.

Do keep it read-only during an exam. Don't offer a way to pause or disable protection.
