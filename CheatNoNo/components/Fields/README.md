Form controls are native elements styled with CheatNoNo classes: text input, textarea, checkbox, radio, switch, segmented control, stepper, tags, and banners for form-level messages.

The consumer provides a `label` for every control, helper text in `cn-hint`, and an error with an icon in `cn-hint--error`. Inputs are 16px and 48px tall so phones never zoom. Use a switch for settings that apply immediately, a checkbox for choices in a list, the segmented control for mode choices (Enforce or Record only) and the stepper for small numbers (strikes).

Do validate when the field is left, not while typing. Don't use placeholder text as a label.
