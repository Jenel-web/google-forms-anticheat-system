The test editor is a single page where a teacher pastes a Google Form link and sets strikes, mode, snap-back, blocked categories and sites, allow-list, fullscreen, copy and paste, and whether to log page titles.

The consumer provides the form lookup result and saves the settings. Use `cn-setting` rows with the right control for each setting; keep Log page titles off by default and explain why. On phones a sticky action bar holds Save draft and Publish test; from 1180px a checklist panel sits beside the form.
