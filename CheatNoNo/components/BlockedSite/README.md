The blocked-site page is what a student sees if they reach ChatGPT, Gemini or any blocked site during an exam: the domain, Blocked during your exam, and This attempt was recorded.

The consumer provides the domain, the blocked category chip and the mode. In enforce mode a warning banner reports the strike added; in record-only mode an info banner says no strike was added. One button returns to the exam.

Do show the domain only. Don't show page titles or any content from the blocked site.
