CheatNoNo uses one in-house line icon set on a 24px grid with a 1.75px round stroke, drawn in `currentColor`.

The consumer provides inline SVG using the `cn-ico` class (20px by default; 14px inside chips, 28px inside modal icons) and sets the color through the parent. Pair an icon with every status chip, detection row and event in the timeline.

Do use icons to name events, not to decorate. Don't use emoji, filled glyphs or a second icon family.
