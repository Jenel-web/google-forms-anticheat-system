Buttons are rounded 12px, at least 44px tall, and use verbs for labels.

Use `cn-btn--primary` for the one main action on a screen (Start exam, Return to exam, Publish test), `cn-btn--secondary` for alternatives, `cn-btn--ghost` for low-emphasis actions and `cn-btn--danger` only for locking or destructive actions. Sizes: `cn-btn--lg` for student overlays, default for the dashboard, `cn-btn--sm` in table rows and cards. Add `cn-btn--block` on phones when the button is the screen's main action. The consumer provides the label and an optional leading `cn-ico`.

Do keep one primary button per card. Don't use `brand` as a button fill; small white text on it is only 3.4:1.
