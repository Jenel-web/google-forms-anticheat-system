The CheatNoNo logo is a shield-and-check mark with an amber strike dot, paired with a Sora wordmark that reads Cheat in navy and NoNo in light blue.

The consumer provides the surface: use `cn-logo` on white or light blue, add `cn-logo--on-ink` on navy, `cn-logo--sm` in the sidebar, popup and top bar, `cn-logo--lg` on sign-in and hero areas.

Do write the name as one word, CheatNoNo. Do keep clear space equal to the check's height. Don't recolor the amber dot, outline the mark or place it on `brand` (the shield disappears).
