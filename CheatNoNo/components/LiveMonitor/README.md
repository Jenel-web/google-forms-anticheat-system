The live monitor shows every student during a running test: status chips as filters, a table (cards on phones) with strikes, current question and last seen, an Unlock button on locked rows, and a live alert feed.

The consumer provides the real-time student list and the alert stream. Locked rows use `is-attn` and an Unlock button; the feed lists the newest first. The feed sits beside the table from 1360px and below it on narrower screens. Filters scroll sideways on phones.

Do keep the Unlock button reachable on phones. Don't reorder rows while a teacher is reading them.
