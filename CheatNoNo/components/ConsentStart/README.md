The consent and start screen is the first thing a student sees on an exam page: exam title, detected Google email, name field, a plain list of what is monitored and blocked, consent, and Start exam.

The consumer provides the exam title, teacher and duration, the detected email (or the not-signed-in banner), and the lists of monitored and blocked items from the test settings. Start exam stays disabled until the student is signed in, has a name and has agreed; the click also enters fullscreen. Under 760px the two lists stack.

Do keep the lists honest and specific. Don't hide what is blocked in a link.
