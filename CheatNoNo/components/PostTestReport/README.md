The post-test report summarizes a finished test: class totals, students ranked by integrity score, a question heatmap showing where students left, and CSV and PDF export.

The consumer provides the scores and the per-question counts. Bars use `success`, an outlined `amber` or `danger` by band, and always print the number. Heatmap cells print the count, so color is never the only signal. The heatmap wraps to the container width.

Do list the lowest scores first for review. Don't rank students publicly.
