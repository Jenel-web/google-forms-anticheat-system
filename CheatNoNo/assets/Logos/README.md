The CheatNoNo mark and app icon, both multi-color SVGs meant for `<img>`.

`cheatnono-mark.svg` is the shield with the check and amber strike dot on a transparent ground; use it on white and light blue at 16px and up. `cheatnono-app-icon.svg` places the mark on a `surface-sky` rounded square; use it for the Chrome extension icon (export to 16, 32, 48 and 128px PNG), the web app icon and social previews. The wordmark is live type (Sora Bold), not an image: see the Logo card.
