Get set up before exam day.

Install the CheatNoNo extension once. It takes about two minutes and works on a laptop or desktop in Chrome or Edge.

Three steps

  1. Install the extension
    Add CheatNoNo from the Chrome Web Store.
  2. Sign in to your school Google account
    Use the same account you use for the exam form.
  3. Run the self-check
    Make sure everything passes before the exam starts.
