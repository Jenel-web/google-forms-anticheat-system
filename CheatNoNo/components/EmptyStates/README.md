Empty and error states cover no tests yet, no students joined, extension not detected and offline.

The consumer provides one primary action per state. Use `cn-empty` with an icon in a light-blue disc (the aqua and amber dots echo the logo); switch the disc to `danger-bg` for errors. Offline keeps the last data visible, dimmed, under a warning banner with the time of the last update.
